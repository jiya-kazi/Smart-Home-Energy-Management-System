# Module 3 – Real-Time Energy Tracking

## About Module 3
Module 3 is responsible for **Real-Time Energy Tracking** in the Smart Home Energy Management System (SHEMS).  
This module focuses on **monitoring, calculating, and recording energy consumption** generated by smart devices managed in Module 2.

It ensures that every device’s power usage is continuously tracked and stored for analysis, reporting, and optimization.

---

## Responsibilities of Module 3
- Track real-time energy consumption of smart devices
- Calculate energy usage based on device power ratings and usage duration
- Store energy consumption records
- Provide energy data for analytics and scheduling modules

This module acts as the **energy monitoring layer** of the system.

---

## Functional Features

### Energy Tracking Functions
- Track device ON/OFF duration
- Calculate energy consumption per device
- Maintain historical energy usage records
- Associate energy data with users and devices

## Core Components

### EnergyUsage Entity
Represents energy consumption data with attributes such as:
- Device reference
- User reference
- Power consumed
- Usage duration
- Timestamp

---

### EnergyTrackingController
Handles requests related to:
- Viewing energy usage data
- Fetching real-time consumption
- Displaying energy reports

---

### EnergyTrackingService
Contains logic for:
- Calculating energy consumption
- Aggregating usage data
- Preparing data for analytics

---

### EnergyTrackingRepository
Handles persistence of energy usage records using Spring Data JPA.
